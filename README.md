# Учебный shell: лексер

## Сборка

```sh
make
```

Сборка использует GCC, стандарт C23, флаги `-Wall -Wextra` и макрос `_POSIX_C_SOURCE=200809L`.

Отладочная сборка с AddressSanitizer, UndefinedBehaviorSanitizer и отладочной информацией:

```sh
make debug
```

Удаление собранной программы:

```sh
make clean
```

Цель `make test` запускает скрипт `tests/test.sh`.

## Запуск

Разбор строки, переданной через `-c`:

```sh
./myshell -c 'echo "hello world" | cat'
```

Чтение стандартного ввода с выводом токенов:

```sh
printf 'echo "hello world" | cat\n' | ./myshell --dump-tokens
```

Чтение из файла:

```sh
./myshell < commands.txt
```

Интерактивный ввод:

```sh
./myshell
```

При запуске без аргументов из терминала программа показывает приглашение `mysh> ` и разбирает введённые строки. Для завершения используется Ctrl-D. Слово `exit` обрабатывается как обычный токен.

В режиме `--dump-tokens` программа читает стандартный ввод до конца файла, затем выводит токены и завершается.

## Возможности лексера

- Распознавание слов и операторов `|`, `&`, `;`, `&&`, `||`, `(`, `)`, `<`, `>`, `>>`.
- Выбор более длинного оператора при совпадении: например, `>>` вместо двух `>`.
- Обработка одинарных и двойных кавычек.
- Склейка соседних фрагментов слова: `a"b c"d` образует слово `ab cd`.
- Сохранение пустых слов, заданных через `""` или `''`.
- Экранирование символов обратной косой чертой.
- Обработка продолжения строки в переданном лексеру тексте.
- Пропуск комментариев, начинающихся с неэкранированного `#` вне кавычек в начале слова.
- Выделение неэкранированного перевода строки вне кавычек в токен `NEWLINE`.
- Добавление токена `EOF` в конце ввода.

Внутри одинарных кавычек символы сохраняются буквально. Внутри двойных кавычек обратная косая черта экранирует только `"`, `\` и перевод строки.

## Формат вывода

Для каждого токена выводятся позиция, тип и текст, если он есть.

Пример:

```sh
printf 'echo hi\n' | ./myshell --dump-tokens
```

Результат:

```text
1: WORD          "echo"
6: WORD          "hi"
8: NEWLINE
9: EOF
```

Позиция считается в байтах исходного ввода, начиная с единицы. Для текста в UTF-8 она может отличаться от номера видимого символа.

## Ошибки и ограничения

Диагностика лексических ошибок выводится в `stderr` с указанием позиции. При ошибке лексера возвращается код `2`.

Лексер не проверяет грамматическую правильность последовательности токенов. Например, строка `echo &&` разбивается на токены без проверки наличия команды после `&&`.

Интерактивный режим пока обрабатывает каждую введённую строку отдельно. Автоматическое дочитывание продолженного ввода со вторичным приглашением не реализовано.

Выполнение команд, перенаправление потоков, запуск конвейеров, встроенные команды и управление заданиями отсутствуют. Соответствующие операторы только распознаются лексером.

Подстановки переменных, раскрытие шаблонов имён файлов и другие расширения shell не реализованы. Полная проверка неподдерживаемых конструкций пока не реализована.
